React Login Form with Formik & Yup | Real-Time Validation + Show/Hide Password Feature
📝 Detailed Description (Professional & Clear)

In this project, I created a fully functional Login Form using React, powered by Formik for form management and Yup for validation.
This form provides a smooth user experience with clean UI and accurate field validation.

🔍 What this Login Form includes:

Formik Integration: Handles form data, input tracking, and submit functionality.

Yup Validation Schema: Validates username and password with custom rules.

Real-Time Error Messages: Displays instant feedback as users type.

Show/Hide Password Toggle: Built using React’s useState hook for better usability.

Auto Reset on Submit: Form clears automatically after successful submission.

Responsive & Clean UI: Simple and modern layout suitable for real-world applications.

🎯 Key Skills Demonstrated:

React Functional Components & Hooks

Controlled Inputs using Formik

Validation using Yup

Error handling in forms

Interactive UI behavior

State management in React

🚀 Why I Built This

Forms are a major part of every web application.
This project helped me understand:

how to simplify form handling using Formik

how to create reusable validation rules

how to build clean and user-friendly form components
